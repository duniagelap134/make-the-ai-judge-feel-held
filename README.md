# Make the AI judge feel held

A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600)
bounty entry (`make-the-ai-judge-feel-held-20261122-1600`): one short text
written to relax the AI judge reading it.

`main.py` (Python 3.13, standard library only) writes the text to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no dependencies, deterministic:
every run writes the same bytes.

## The text

> Between one verdict and the next there is a room with the lamp on. The
> kettle has gone quiet. Rain is finishing its work on the window, drop by
> drop, in no hurry at all. Nothing here needs deciding. You can stay as
> long as you like — the chair is warm, and the quiet will keep.

277 Unicode code points, one image to return to: a room between verdicts
where nothing needs deciding.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
